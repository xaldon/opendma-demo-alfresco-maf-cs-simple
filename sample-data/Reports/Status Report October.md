# Project Apollo Status Report - October

Reporting period: October 2026

## Summary

Project Apollo is now at risk of missing the planned production cutover.

Northwind Components reported a six-week delay for the production hardware
batch. The migration team can continue testing, but the production cutover
cannot start without that hardware.

## Schedule impact

The current cutover date is no longer realistic unless the supplier provides a
partial shipment or an alternative hardware model. The project manager estimates
a four to six week schedule impact.

## Additional concerns

The revised cutover date may fall outside the support window currently reserved
with Contoso Managed Services.

The project manager also expects the supplier delay to increase internal run
costs for the migration team if the cutover moves by more than four weeks.

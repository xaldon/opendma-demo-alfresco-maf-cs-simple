# Supplier Agreement

Project: Project Apollo
Supplier: Northwind Components
Effective date: 2026-08-01

## Delivery milestones

Northwind Components supplies the integration gateway hardware used by the
Project Apollo content migration platform.

The current delivery milestone for the production hardware batch is 2026-11-15.
The supplier notified the project team that the batch is expected to arrive six
weeks late because of a component shortage.

## Dependency

The content migration dry run can continue with the existing test hardware, but
the production cutover depends on the production hardware batch.

## Penalty clause

The agreement includes service credits for delivery delays after 2026-11-15.
These milestone penalties apply when the production hardware delivery milestone
is missed by more than ten business days.
The service credits do not compensate Project Apollo for internal project delay
costs or missed regulatory milestones.
